# Security Policy for Kirby Plugin: Listsubpages

Nobody is perfect – we also have security vulnerabilities. If you discover one, we would appreciate it if you could help us fix it. Our primary focus is to eliminate the root cause as quickly as possible and minimize potential damage, particularly to third parties. A constructive, respectful approach is important to us.

So, please, let us know if you've discovered a security issue. However, we do not pay bounties for finding and reporting security vulnerabilities.

## Supported Plugin Versions

| Plugin Version | Supported          |
| :------------: | :----------------: |
|     1.x.x      | :white_check_mark: |
|     < 1.0      | :x:                |

**Explanation:**

:white_check_mark: means that this version (or these versions) of the plugin is (are) supported by security updates

:x: means that this version (or these versions) of the plugin is (are) NO LONGER supported


## Reporting a Vulnerability

We take security vulnerability reports seriously and are grateful for help in closing them. To ensure this process runs as smoothly and quickly as possible, here are some tips for efficiently **reporting security vulnerabilities** to us:

- Please send an email written in **German** to bugs@heineref.de with the subject line 'Sicherheitslücke im Plugin listsubpages'
- Describe as specifically as possible **where** you found the bug. Give us a URL, IP, or whatever coordinates you have.
- Describe exactly what happens **when** the bug is triggered.
- Describe step by step **how** we can reproduce it.
- Sometimes it helps to explain **why** this is a problem or what could happen in the worst case due to these vulnerabilities. (Note: We certainly know what XSS is and why it's dangerous, for example. But occasionally the situation is less clear, and your assessment helps us evaluate the issue)
- Finally, feel free to give us any tips on **how** we could resolve the issue.
- It would be nice to provide us with **a way to reach you** for any follow-up questions; however, we also accept anonymous tips.


We’ll get back to you as soon as possible—usually by the following weekend—since we work full-time in our main jobs during the week and can only handle website-related tasks on the weekends.

If you do not write in **German**, we will have to spend an unnecessary amount of time translating your message into our native language. In particular, correctly translating the technical IT aspects that are typically included in such messages will take us significantly more time than it would take you, as an expert in the field. Technical terms should, of course, be written in English.
Only then can we understand and process your message.
